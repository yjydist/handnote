##### 测试集包含 107 份笔记，单份笔记可由多页内容构成，数据集涵盖原始轨迹、笔记截图、笔记插图，以及插图对应的位置信息。

##### 【文件清单】

###### allStroke.json：原始轨迹数据

格式：JSON (.json)

结构：根节点为一个标准的 JSON Array (列表)，列表中的每个元素代表一条独立的“笔画 (Stroke)”，列表顺序为笔画书写顺序。

【数据结构示例】

[

{

"brush_style": "pen",

"start_time": 0,

"pen_width": 3,

"pen_color": 255,

"points": [

{

"x": 26.32,

"y": 57.74,

"time": 0

}

]

}

]



【字段详细说明字典】

brush_style (String) - 笔刷样式 / 绘图工具

[枚举值及建议用途]

"pen" : 钢笔 

"ballpoint_pen" : 圆珠笔 

"pencil" : 铅笔

"marker" : 马克笔

"brush_highlighter" : 荧光笔

"brush_chinese_pen" : 毛笔/国画笔

"mosaic" : 马赛克

"painting_pencil" : 2B铅笔

"painting_pen" : 秀丽笔 

"painting_ink" : 毛笔



pen_width (Float/Integer) - 笔刷粗细，笔画的基准宽度。



pen_color (Integer/String) - 笔刷颜色，笔画的颜色值。



points (Array of Objects) - 点阵轨迹序列，构成该笔画的极简时空点阵集合。
[包含字段]

"x" (Float) : 点的 X 坐标

"y" (Float) : 点的 Y 坐标

"time" (Integer/Float): 该点的相对时间戳



###### PageElement.json: 原始笔记的插图信息，若为空，表示无插图

【数据结构示例】

[

{

   "element_type": "image",

   "image_name": "39b5c33a8fa148ca80022b0b206bfb1f.png",

   "bounding_box": {

     "top": 114.37,

     "bottom": 371.79,

     "left": 125.71,

     "right": 363.73

   },

   "layout_style": {

     "z_index": 4,

     "angle": 0,

     "scale": 1

   }

 }

]



【字段详细说明】

1. element_type (String) - 元素类型，固定为 "image"。

2. image_name (String) - 纯图片文件名。

3. bounding_box (Object) - 图像在画布上的绝对边界框 (top, bottom, left, right)。

4. layout_style (Object) - 图片专有的排版样式

  - "z_index" : 渲染层级，数字越大越在顶层，用于判定图片是“充当背景”还是“覆盖在文字上方”。

  - "angle"   : 图片旋转角度。

  - "scale"   : 图片缩放比例。
